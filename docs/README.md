## ВВЕДЕНИЕ

Базовой целью проектной практики являлась разработка полноценного статического веб-сайта, посвященного проекту, в котором я состою, и работе, которая ведется членами группы. Вариативной целью проектной практики являлась разработка telegram-бота, связанного с тематикой проектной деятельности.

В задачи практики входило:
- изучение и анализ документации по выполнению работ в музеях членами группы проектной деятельности;
- разработка собственной концепции использования и работы telegram-бота, анализ аналогичных концепций у известных представителей этой области;
- анализ литературы и/или других источников информации по теме создания и налаживания работы telegram-ботов;
- создание статического веб-сайта (HTML/CSS) для представления проекта;
- освоение инструментов Git (создание репозиториев) и Markdown (ведение документации);
- формирование конечного отчёта, защита практики по дисциплине.

Практика проходила в период с 03 февраля 2026 г. по 24 мая 2026 г. под руководством куратора от кафедры «Информатика и информационные технологии».

## 1. Общая информация о проекте

### Название проекта:
Героизм надо помнить.

### Цели и задачи проекта:
Цель проекта – работа по сохранению и охране памяти подвигов наших соотечественников в годы ВОВ (Великой Отечественной войны) путём создания музейных центров, выставок по всей стране, работы с советами ветеранов, школами, музеями и ВУЗами.

**Задачи:**

1. Учредить музейный центр «Соколиная гора», подготовить экспозицию для центра.
2. Создать экспозицию, посвященную поисковику Сергею Анатольевичу Бурулину и основательнице музея 2 ДНО Сталинского района г. Москвы Евтеевой Зое Семеновне. Информационный стенд и экспозицию разместить в музее 2 ДНО Сталинского района г. Москвы, находящемся в школе №1362 Измайловского района г. Москвы.
3. Создать экспозицию музея воинской славы Московского Инструментального Завода (МИЗ).
4. Создать статический веб-сайт, посвященный работе проекта.
5. Создать telegram-бота, связанного с темой проектной деятельности.
6. Подготовить полную документацию, перенести документацию в репозиторий GitHub.
7. Выложить код для заданий базовой и вариативной частей проектной практики в репозиторий GitHub.

## 3. Описание задания по проектной практике

Задание по проектной практике состояло из двух частей: обязательной (написание сайта, посвящённого теме проектной деятельности с использованием HTML/CSS) и вариативной (разработка telegram-бота с развлекательным функционалом по теме, близкой к теме проектной деятельности. Был выбран вариант с образовательной викториной на тему фактов из истории ВОВ).

### Обязательная часть:

1. Изучить язык разметки Markdown и его синтаксис и вести документацию в этом формате;
2. Создать статический веб-сайт (не менее 5 страниц), включающий в себя:
   1) Домашнюю страницу с аннотацией;
   2) Страницу «О проекте» с более подробным описанием работы;
   3) Страницу «Участники» с указанием ролей участников;
   4) Страницу «Журнал» с минимум тремя постами/новостями/записями о прогрессе работы;
   5) Страницу «Ресурсы» с указанием полезных материалов (при их наличии) и каналов связи с куратором и заказчиком проекта;
3. Оформить сайт с помощью HTML/CSS, обеспечить работоспособность сайта и разместить код на GitHub.

### Вариативная часть:

- Провести анализ известных telegram-ботов и механизмов их взаимодействия с пользователем.
- Изучить литературу и/или другие источники информации, связанные с созданием и работой telegram-ботов.
- На основе анализа вышеприведенных данных разработать концепцию бота в соответствии с темой проектной деятельности.
- Создать своего собственного telegram-бота и наладить его стабильную работу.
